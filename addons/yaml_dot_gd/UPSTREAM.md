# YAML.gd provenance

Vendored from <https://github.com/lowlevel-1989/YAML.gd> at commit
`da258fc49ab3de88fb2af6f7400ece3800e779e7` on 2026-08-27.

Only the runtime parser (`yaml.gd`), its Godot UID, and the upstream MIT
license are included. The optional editor plugin and upstream test scenes are
not enabled in this project. Update this dependency deliberately and rerun the
room-layout validation commands afterward.
